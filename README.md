## 🚀 How to Run Locally

You don't need any complex build steps or node packages. You can open `index.html` directly in any web browser, or serve it locally:

### Option 1: Python HTTP Server (Built-in)
Run the following in the project root:
```bash
# Python 3
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

### Option 2: VS Code Live Server
If you use Visual Studio Code, install the **Live Server** extension, right-click `index.html`, and select **"Open with Live Server"**.

## 🌐 How to Publish Online with a Free Public URL

Here are three free hosting methods to deploy your portfolio in under 3 minutes:

### 1. GitHub Pages (Recommended — 100% Free & Fast)

1. Create a free account at [github.com](https://github.com) if you haven't already.
2. Create a new repository named `portfolio` (or `username.github.io`).
3. In your local terminal inside `sampada-navalli-portfolio/`, run:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of portfolio"
   git branch -M main
   git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/<REPO_NAME>.git
   git push -u origin main
   ```
4. On GitHub, go to your repository **Settings** → **Pages** (left sidebar).
5. Under **Build and deployment**:
   - Source: `Deploy from a branch`
   - Branch: `main` / folder: `/ (root)`
6. Click **Save**. Within 1–2 minutes, your website will be live at:
   `https://<YOUR_GITHUB_USERNAME>.github.io/<REPO_NAME>/`

---

### 2. Netlify (Drag & Drop — No Git Required)

1. Go to [app.netlify.com](https://app.netlify.com) and log in (or sign up for free).
2. Go to the **Sites** tab.
3. Simply **drag and drop** the entire `sampada-navalli-portfolio` folder into the Netlify drop zone.
4. Netlify will immediately deploy your site and provide you with a live URL (e.g., `https://sampada-navalli.netlify.app`).
5. (Optional) You can customize the free subdomain under **Site configuration** → **Change site name**.

---

### 3. Vercel (Instant Deploy with CLI or GitHub)

#### Via Vercel Web:
1. Push your repository to GitHub.
2. Go to [vercel.com](https://vercel.com) and log in with GitHub.
3. Click **"Add New Project"** and select your portfolio repository.
4. Keep default settings (Framework: *Other*) and click **Deploy**.
5. Your portfolio is immediately live with free SSL and worldwide CDN (e.g., `https://sampada-portfolio.vercel.app`).

#### Via Vercel CLI (Terminal):
```bash
npm i -g vercel
vercel
```
Follow the 3 short prompts and your portfolio will be published instantly!
